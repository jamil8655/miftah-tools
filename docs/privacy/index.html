English: All document manipulation, OCR text extraction, PDF merging/splitting, and media processing execute exclusively within the local browser and device memory sandbox. Zero files are uploaded or stored on any remote server.

Used strictly when you scan QR codes/Barcodes or capture a profile photo. Camera frames are processed in real-time memory and never uploaded.

Used exclusively when you select files, PDFs, or photos from your device for local editing, compression, or format conversion.

Required for Firebase user authentication, sync, and displaying AdMob advertisements.

Strictly conforms to Android Scoped Storage guidelines. The app cannot access any files outside what you explicitly select.
